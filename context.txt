PROJECT OVERVIEW:
Transform Ultron from a command-based bot into a personalized AI assistant that:
- Learns user preferences and knowledge
- Retrieves relevant context before responding
- Provides personalized, context-aware answers
- Supports multi-user personalization

STEP 3.2: Create retriever.py
File: retriever.py
Purpose: Retrieve relevant context for queries

Key Functions:
  - retrieve(query, user_id="default", top_k=3, threshold=0.6)
    Find relevant documents for a query
    Return only results above similarity threshold
    
  - filter_by_metadata(results, filters)
    Additional filtering by category, source, etc.
    
  - format_context(results)
    Format retrieved docs for LLM injection
    
Example Usage:
  results = retriever.retrieve("authentication best practices", user_id="user1")
  context = retriever.format_context(results)
  # Returns: "Based on your knowledge base:
  #           1. Use JWT tokens (score: 0.92)
  #           2. Refresh token rotation (score: 0.88)"

================================================================================
TROUBLESHOOTING CHECKLIST
================================================================================

Issue: Embeddings too slow
→ Use GPU: pip install faiss-gpu
→ Or use smaller model: all-MiniLM-L6-v2 (fast, good quality)

Issue: Out of memory
→ Use Chroma instead of FAISS (lighter)
→ Reduce chunk_size in chunking
→ Process documents in batches

Issue: Retrieved results irrelevant
→ Increase top_k (search more results)
→ Lower similarity threshold
→ Check document quality in ingest

Issue: User isolation not working
→ Verify user_id is passed to all retrieval calls
→ Check vectorstore.py namespace filtering
→ Clear and rebuild index

Issue: Voice response delays
→ Cache embeddings for common queries
→ Use async retrieval
→ Reduce model complexity


================================================================================
PERFORMANCE OPTIMIZATION TIPS
================================================================================

1. EMBEDDING CACHING
   Cache query embeddings for 5 minutes
   Avoid re-embedding same queries

2. BATCH INDEXING
   Index documents in batches of 100
   Faster than one-by-one

3. VECTOR COMPRESSION
   Use product quantization (PQ) in FAISS
   Reduces memory by 10-100x

4. QUERY OPTIMIZATION
   Use filters before similarity search
   Narrow search space by user_id first

5. PRECOMPUTE COMMON QUERIES
   Pre-index FAQ answers
   Fast retrieval for common questions
